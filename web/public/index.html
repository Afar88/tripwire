🛡️ Tripwire
Live on NEAR testnet

Check a NEAR account before anyone pays it.

AI agents can now send money on their own. One poisoned prompt can swap the payee for a drainer. Tripwire asks an on-chain scam registry first and answers ALLOW, WARN or BLOCK, with reasons.

How it works

1 · Registry contract

An on-chain list of flagged accounts. Anyone calls get_risk; trusted reporters file flags with a reason and evidence.

2 · Checker

Reads the registry over public RPC, adds lookalike-name and "account doesn't exist" checks, returns a verdict. Can't reach the registry? It warns, never silently allows.

3 · Guard vault

An agent's wallet that can only request spends. It enforces caps and asks the registry on chain: paid, blocked, or held for the owner. Failed transfers are refunded.

4 · NEAR AI second opinion

NEAR AI Cloud reads the payment's purpose. It can only raise ALLOW to WARN, never unblock anything.
